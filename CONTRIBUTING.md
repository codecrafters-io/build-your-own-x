# Contributing to Build Your Own X

We welcome contributions to this curated list of programming tutorials!

## How to Contribute

1. Fork the repository.
2. Read the existing list structure to match category alignments.
3. Make sure the tutorial you are adding is comprehensive, high-quality, and teaches the reader how to build the technology from scratch.
4. Add the tutorial link to the correct category in alphabetical order.
5. Submit a Pull Request.
